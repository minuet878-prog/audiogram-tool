# Roadmap

## 已完成

### v1（2026-10-08）
- 左右耳分開輸入：氣導 250–8000 Hz、骨導 500–4000 Hz
- 四頻平均（500/1000/2000/4000 Hz）、聽損程度、聽損類型
- SVG 聽力圖：右耳紅圈、左耳藍叉，氣導連線；骨導 < 和 >，不連線
- 輸入檢查：-10 到 120、5 的倍數
- 55 個測試

### v2 視覺優化（2026-10-08）
- 套用 Bootstrap 5.3.3（下載放在 `static/css/`，離線可用）
- 桌機左右並排：左邊輸入，右邊結果卡加聽力圖；手機改成上下排，輸入表不用左右滑
- 結果卡依程度上色（綠 → 深紅），上緣是耳別色條
- 聽力圖：圖例、正常範圍（≤25）淺綠底、軸標題、0 dB 粗線、骨導符號加大加粗
- 錯誤訊息改用紅色警示框，錯的格子框線變紅
- 77 個測試
